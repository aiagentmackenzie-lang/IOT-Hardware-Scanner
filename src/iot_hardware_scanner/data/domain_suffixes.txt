# Public domain suffixes this scanner treats as a plausible hostname suffix.
#
# A domain indicator is a claim about a name a device would resolve. A token in
# a binary's string table that merely contains a dot is not that claim: on a
# stock OpenWrt image the previous behaviour reported `libc.so`,
# `lucihttp.parser.urlencoded`, `payload.offset` and `pf.os` as C2 domains,
# because a token with a dot and a "top-level domain" of any length was
# accepted.
#
# Two rules follow from that and are enforced in
# intelligence/domain_scorer.py::plausible_domain:
#
#   1. The final label must appear in this list. An unlisted suffix is not a
#      domain indicator, whatever else the token looks like.
#   2. The token must not be the basename of a file in the image, a library
#      soname, or a `.so`-shaped name. A dependency name is a dependency name.
#
# The list is deliberately bounded and is recorded in the report as a data
# source with its digest. It is a *minimum*: names under a suffix that is not
# listed are missed rather than guessed at. Broaden it with a current public
# suffix list when one is supplied as an explicit input.
